PROTOTYPE · File operations window (Gozler)

A Total Commander stacked: only standard controls.   B Windows 11 card: the card and its thin blue bars are painted by Gozler.   B1 the same card with the standard Win32 progress bars: only the card is painted.
In B and B1 the queue is a standard ListView in tile view. Drag a waiting operation to change the order: the black line is the ListView's own insertion mark. No line means that place is refused, because the operation's paths overlap one it would pass. The ↑ ↓ × buttons in the queue header, and a right-click on a row, do the same for the selected row. Delete cancels the selected row. The "Waiting for" lines follow the new order.
